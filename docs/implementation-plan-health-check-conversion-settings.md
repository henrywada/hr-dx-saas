# 設計計画: 健康診断 他機関→標準の変換式設定

`/adm/health-check/settings` から、他機関データをテナント標準機関基準へ寄せる変換ルールを登録・削除できるようにする。

---

## 1. 問題定義

変換の実行ロジック（`src/features/health-check/convert.ts`）とテーブルは既にあるが、設定画面に入力 UI が無く、ルールを登録できなかった。

標準機関（`is_standard`）の取込は恒等コピーのまま変えない。変換式は **他機関の取込時のみ** 使う。

---

## 2. ユーザーストーリー

- 人事は、他機関の判定コードを標準判定コードへ対応づけられる
- 人事は、検査項目ごとに単位換算（倍率）を登録できる
- 人事は、標準機関のカットオフ（閾値）を登録し、他機関の数値を再判定できる
- 人事は、対応づけの前提となる標準判定コードを追加・削除できる

---

## 3. 要求優先度

| 優先度   | 内容                                               |
| -------- | -------------------------------------------------- |
| Must     | 設定タブに変換式セクション（判定対応・単位・閾値） |
| Must     | 標準判定コードの追加・削除                         |
| Must     | 手入力保存でも同じ変換表を適用する                 |
| Must not | 標準機関データへの変換（恒等のまま）               |
| Must not | 新規テーブル・マイグレーション                     |

---

## 4. データモデル（既存）

| テーブル                          | 用途                                     |
| --------------------------------- | ---------------------------------------- |
| `health_check_judgment_codes`     | テナントの標準判定コード                 |
| `health_check_judgment_code_maps` | 他機関の生コード → 標準判定              |
| `health_check_unit_conversions`   | 他機関単位 → 標準単位（倍率）            |
| `health_check_item_thresholds`    | 標準機関カットオフ（他機関の数値再判定） |

新規テーブルは作らない。

---

## 5. 配置

- URL: `/adm/health-check/settings`（既存）
- UI: `src/features/health-check/components/ConversionSettingsPanel.tsx`
- SELECT: `queries.ts` / 書き込み: `actions.ts`

---

## 6. 成功指標

- 他機関を選んで判定コード対応を追加・削除できる
- 単位変換・閾値を追加・削除できる
- 標準機関の CSV 取込は従来どおり変換しない
- 他機関の CSV / 手入力で登録したルールが `convert.ts` 経由で適用される

---

## 7. オープンクエスチョン

単位変換・閾値は **機関別**（`institution_id`）。設定画面の「適用する機関」と変換式セクションは同じ選択を共有する。
