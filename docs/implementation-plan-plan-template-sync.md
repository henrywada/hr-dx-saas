# 実装計画: プランテンプレート同期

作成日: 2026-08-15

## 1. 問題定義

Planテンプレート（プラン条件・テナント×サービス・ダッシュボード表示）を変えても、既に契約中のテナントへは自動反映されない。

## 2. ユーザーストーリー

- SaaS管理者として、プラン条件タブの各行から、同じ契約タイプの既存テナントへ最新テンプレートを一括反映したい。

## 3. 要求と優先度

| #   | 要求                                                                                      | 優先度 |
| --- | ----------------------------------------------------------------------------------------- | ------ |
| R1  | 各プラン行の「保存」の右に「同期」を置く                                                  | MUST   |
| R2  | 対象は `plan_type` が一致し `is_template=false` のテナント                                | MUST   |
| R3  | 反映内容は保存済みプラン条件の最大人数、テンプレートの tenant_service、ダッシュボード表示 | MUST   |
| R4  | テンプレートテナント自身は更新しない                                                      | MUST   |
| R5  | 契約終了日・決済状態・テナント稼働状態は上書きしない                                      | MUST   |

## 4. 配置

- 判定ヘルパー: `src/features/plan-config/sync.ts`
- Server Action: `syncPlanToExistingTenants`（`actions.ts`）
- UI: `src/features/plan-config/components/PlanConfigTab.tsx`

## 5. 成功指標

- 同期後、対象テナントの最大人数・有効サービス・ダッシュボード表示がテンプレートと一致する
- テンプレート不在またはサービス0件のときは更新せずエラーを返す
