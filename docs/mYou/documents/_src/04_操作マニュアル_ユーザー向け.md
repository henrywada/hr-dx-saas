## 1. はじめに

### 1.1 本書について

本書は、ミュー株式会社の入荷・出荷・照会を担当される方が、製品トレーサビリティ・有効期限管理システム（以下「本システム」）を日常業務で操作するための手引きです。

マスタ保守・アラート送信・アカウント管理については、別冊「操作マニュアル（管理者向け）（MYOU-AM-001）」をご覧ください。

### 1.2 本システムでできること

本システムは、スプレー缶製品「セルフィール MS」を **製造ロット単位** で管理し、流通履歴と有効期限をデジタルで記録・照会するためのものです。

| 機能         | 内容                                                                               |
| ------------ | ---------------------------------------------------------------------------------- |
| 入荷登録     | 製造元から納品された段ボール（ロット）のQRをスキャンし、数量を入力して在庫登録する |
| 在庫一覧     | 未出荷の在庫を、有効期限が近い順に一覧表示する                                     |
| 出荷登録     | 施工会社への出荷を登録し、トレーサビリティQRを発行・印刷する                       |
| 出荷リスト   | これまでの出荷実績を確認し、使用数を記録する                                       |
| トレース照会 | ロット番号またはTraceNoから流通履歴を検索する                                      |
| 有効期限監視 | 期限が近い出荷済み製品を確認する（メール送信は管理担当者が実施）                   |

### 1.3 用語

| 用語               | 意味                                                            |
| ------------------ | --------------------------------------------------------------- |
| ロット             | 製造単位。段ボール1箱に相当し、複数本のスプレー缶が入っています |
| ロット番号         | ロットを識別する番号。`LOT-20260729-0001` のような書式です      |
| ロットQR           | 段ボールに貼られているQRコード                                  |
| トレーサビリティQR | 出荷時に発行し、製品に貼るQRコード                              |
| TraceNo            | 出荷1件ごとに発行される番号。`20260729-0001` のような書式です   |
| 残数               | そのロットに残っている、出荷できる本数                          |
| 使用数             | 出荷した製品のうち、施工会社で使用されたことが分かっている本数  |

## 2. ログインと画面の開き方

### 2.1 ログイン

1. ブラウザで `https://app.hr-dx.jp` を開きます
2. メールアドレスとパスワードを入力してログインします
3. ダッシュボード画面が表示されます

### 2.2 各機能への移動

1. サイドメニューから **「製品トレーサビリティ」** を選びます
2. 目的の機能のカードボタンをクリックします

| メニュー名             | 用途                                   |
| ---------------------- | -------------------------------------- |
| 入荷登録（QRスキャン） | 製造元から納品された製品の在庫登録     |
| 在庫一覧               | 未出荷在庫の確認                       |
| 出荷登録（QRスキャン） | 施工会社への出荷登録                   |
| 出荷リスト             | 出荷実績の確認・使用数の記録           |
| トレーサビリティ検索   | ロット番号／TraceNoによる履歴照会      |
| 有効期限監視・アラート | 期限が近い出荷済み製品の確認           |
| 納入先登録             | 施工会社マスタの保守（管理担当者向け） |
| 資料一覧               | 操作資料・システム仕様書の閲覧         |

> 画面どうしの直接リンクはありません。別の機能へ移るときは、画面右上の **「戻る」** からメニューに戻って選び直してください。

### 2.3 ヘルプボタン

各画面の右上には **ヘルプボタン** があります。操作に迷ったときは、その場で操作要点を確認できます。

## 3. 日常業務の流れ

日常業務では、次の順序で操作します。

```
① 入荷登録        製造元から納品されたとき
     ↓
② 在庫確認        受注を受けたとき（期限が近い在庫から引き当てる）
     ↓
③ 出荷登録        施工会社へ出荷するとき
     ↓            → トレーサビリティQRを印刷して製品に貼付
④ 照会・確認      問い合わせがあったとき／実績を確認するとき
```

## 4. 入荷登録（製造元からの納品）

**画面：入荷登録（QRスキャン）**

製造元から段ボール（ロット）が納品されたときに、在庫として登録します。

### 4.1 QRコードを読み取って登録する

| 手順 | 操作                                                         |
| ---- | ------------------------------------------------------------ |
| 1    | メニューから **「入荷登録（QRスキャン）」** を開きます       |
| 2    | ブラウザから確認されたら、**カメラの使用を許可** します      |
| 3    | 段ボールのロットQRを **枠内に収めて** スキャンします         |
| 4    | 自動的に入荷処理の画面（モーダル）が開きます                 |
| 5    | **ロット番号・有効期限** を確認します                        |
| 6    | **数量（缶の本数）** を入力します                            |
| 7    | 登録ボタンを押します                                         |
| 8    | メッセージを確認します                                       |
| 9    | 続けて別のロットがある場合は、そのままスキャンを繰り返します |
| 10   | **在庫一覧** で登録内容を確認します                          |

### 4.2 QRコードが読み取れないとき

QRコードが汚れている・破損しているなどで読み取れない場合は、次のように操作します。

| 手順 | 操作                                                      |
| ---- | --------------------------------------------------------- |
| 1    | 画面下部の **「入荷処理へ進む」** ボタンを押します        |
| 2    | ロット番号が **自動採番** されます（`LOT-YYYYMMDD-連番`） |
| 3    | 有効期限と数量を入力して登録します                        |

### 4.3 同じロットが複数回に分けて納品されたとき

同じロットQRを再度スキャンして登録すると、**数量が加算** されます。分納の場合はそのまま登録してください。

### 4.4 メッセージ一覧

| 種別         | メッセージ                                                                 | 意味・対処                                   |
| ------------ | -------------------------------------------------------------------------- | -------------------------------------------- |
| 成功（緑）   | `入荷登録成功: {ロット番号}`                                               | 新しいロットとして登録されました             |
| 警告（黄）   | `{ロット番号} は既に入荷済みです（数量を追加登録しました）。`              | 分納などによる加算。問題なければそのまま     |
| 警告（黄）   | `{ロット番号} は出荷済み（残数0）でしたが、再入荷として在庫に戻しました。` | 返品などの再入荷。内容を確認してください     |
| エラー（赤） | `認証エラー`                                                               | いったんログアウトし、再ログインしてください |
| エラー（赤） | `入荷登録に失敗しました。もう一度お試しください。`                         | 時間をおいて再試行してください               |

## 5. 在庫の確認

**画面：在庫一覧**

未出荷の在庫を確認し、出荷するロットを選びます。

### 5.1 操作手順

| 手順 | 操作                                                           |
| ---- | -------------------------------------------------------------- |
| 1    | メニューから **「在庫一覧」** を開きます                       |
| 2    | 一覧を確認します（有効期限が近い順に並んでいます）             |
| 3    | 必要に応じて **検索バー** でロット番号を検索します             |
| 4    | 列見出しをクリックすると **並べ替え** ができます               |
| 5    | **期限状況が黄色**（残り30日以内）の在庫から優先して出荷します |

### 5.2 表示される項目

| 列         | 内容                                                  |
| ---------- | ----------------------------------------------------- |
| ロット番号 | ロットを識別する番号                                  |
| 残数       | 出荷できる残りの本数                                  |
| 入荷総数   | これまでに入荷した累計本数                            |
| 有効期限   | そのロットの有効期限                                  |
| 入荷日     | 直近で入荷登録した日                                  |
| 期限状況   | 期限切れ（赤）／残りN日（30日以内は黄、それ以上は緑） |

### 5.3 先入れ先出しのお願い

有効期限の近い在庫（**黄色表示**）から優先して出荷してください。出荷登録で残数が0になったロットは、この一覧から自動的に除外されます。

### 5.4 在庫が表示されないとき

「現在、在庫はありません。」と表示される場合は、**入荷登録** がまだ行われていない可能性があります。先に入荷登録を実施してください。

## 6. 出荷登録（施工会社への出荷）

**画面：出荷登録（QRスキャン）**

施工会社へ出荷するときに、出荷先・数量を記録し、トレーサビリティQRを発行します。

### 6.1 まず共通項目を入力する

出荷方法にかかわらず、最初に次の項目を入力します。

| 項目               | 必須 | 内容                             |
| ------------------ | ---- | -------------------------------- |
| 出荷先（施工会社） | 必須 | プルダウンから選択します         |
| 受注数量           | 必須 | 出荷する缶の本数                 |
| 客先注文番号       | 任意 | 施工会社の注文番号（50文字以内） |

> 出荷先を選択しないままスキャンすると、登録されずにエラーとなります。

### 6.2 方法A：在庫表から出荷する（既定のタブ）

| 手順 | 操作                                                           |
| ---- | -------------------------------------------------------------- |
| 1    | **「在庫表より」** タブを開きます                              |
| 2    | 在庫一覧から、出荷したいロットの **「出荷」** ボタンを押します |
| 3    | 表示されたモーダルで数量を確認します                           |
| 4    | 確定すると出荷登録され、QR印刷画面が開きます                   |

### 6.3 方法B：QRコードをスキャンして出荷する

| 手順 | 操作                                           |
| ---- | ---------------------------------------------- |
| 1    | **「QRスキャン」** タブを開きます              |
| 2    | 段ボールのロットQRを枠内に収めてスキャンします |
| 3    | 入力済みの受注数量で自動的に出荷登録されます   |
| 4    | QR印刷画面が開きます                           |

### 6.4 トレーサビリティQRの印刷

出荷登録が完了すると、**トレーサビリティQRの印刷画面** が自動的に開きます。

| 手順 | 操作                                                       |
| ---- | ---------------------------------------------------------- |
| 1    | ロット番号・TraceNo・出荷数量・有効期限を確認します        |
| 2    | **印刷部数** を確認します（初期値は出荷数量。最大1,000部） |
| 3    | **印刷ボタン** を押し、ブラウザの印刷画面から出力します    |
| 4    | 印刷したラベルを製品に貼付します                           |

> 発行されるQRコードは、出荷1件につき **1種類** です。缶ごとに複数枚必要な場合は、同じ内容のQRを必要な部数だけ印刷してご使用ください。

### 6.5 残数が足りないとき

指定した受注数量が、そのロットの残数を超えている場合はエラーになります。システムが自動で別のロットに振り分けることはありません。**別のロットを選び直して** 出荷してください。

### 6.6 メッセージ一覧

| 種別         | メッセージ                                                                | 対処                                       |
| ------------ | ------------------------------------------------------------------------- | ------------------------------------------ |
| 成功（緑）   | `出荷登録成功: {ロット番号}（{数量}個）`                                  | QR印刷画面で印刷してください               |
| エラー（赤） | `先に出荷先（施工会社）を選択してください。`                              | 出荷先を選んでから操作してください         |
| エラー（赤） | `受注数量を入力してください。`                                            | 数量を入力してください                     |
| エラー（赤） | `ロット {ロット番号} が見つかりませんでした。`                            | 未入荷の可能性。入荷登録を確認してください |
| エラー（赤） | `在庫数量が不足しています（残りN個）。別のロットをスキャンしてください。` | 別のロットを選び直してください             |
| エラー（赤） | `出荷登録に失敗しました。もう一度お試しください。`                        | 時間をおいて再試行してください             |

## 7. 出荷リスト（出荷実績の確認）

**画面：出荷リスト**

これまでの出荷実績を確認し、施工会社での使用数を記録します。

### 7.1 操作手順

| 手順 | 操作                                                     |
| ---- | -------------------------------------------------------- |
| 1    | メニューから **「出荷リスト」** を開きます               |
| 2    | 出荷日の新しい順に一覧が表示されます                     |
| 3    | 必要に応じて **出荷先（施工会社）** で絞り込みます       |
| 4    | 使用数を記録する場合は、該当行の **「編集」** を押します |
| 5    | 使用数を入力して保存します                               |

### 7.2 表示される項目

| 列           | 内容                                        |
| ------------ | ------------------------------------------- |
| 出荷日       | 出荷を登録した日                            |
| ロット番号   | 引き当てたロット                            |
| トレースNo   | 発行されたTraceNo                           |
| 得意先No     | 施工会社の番号                              |
| 出荷先       | 施工会社名                                  |
| 客先注文番号 | 入力していない場合は `-`                    |
| 出荷数量     | 出荷した本数                                |
| 使用数       | 施工会社で使用された本数                    |
| 期限状況     | 期限切れ／残りN日。全量使用済みの場合は `-` |

### 7.3 使用数について

- 使用数は **0以上、出荷数量以下** の範囲で入力できます
- 出荷数量と使用数が **同じ**（＝全量使用済み）になると、期限管理の対象から外れ、期限状況が `-` になります
- 使用数は有効期限アラートの対象判定にも使われます（未使用分だけが通知対象になります）

## 8. トレース照会（問い合わせ対応）

**画面：トレーサビリティ検索**

ロット番号またはTraceNoから、製品の流通履歴を照会します。

### 8.1 方法A：番号を手入力する

| 手順 | 操作                                                                                  |
| ---- | ------------------------------------------------------------------------------------- |
| 1    | メニューから **「トレーサビリティ検索」** を開きます                                  |
| 2    | ロット番号（例：`LOT-20260729-0001`）またはTraceNo（例：`20260729-0001`）を入力します |
| 3    | **「履歴を照会する」** を押します                                                     |

### 8.2 方法B：QRコードをスキャンする

| 手順 | 操作                                           |
| ---- | ---------------------------------------------- |
| 1    | **「QRスキャン」** ボタンを押します            |
| 2    | ロットQRまたはトレーサビリティQRを読み取ります |
| 3    | 自動的に照会が始まります                       |
| 4    | 終了するときは **「キャンセル」** を押します   |

### 8.3 確認できる内容

| 区分       | 項目                                                                |
| ---------- | ------------------------------------------------------------------- |
| ロット情報 | ロット番号、現在の状態、残数／入荷総数、有効期限、入荷日            |
| 出荷履歴   | 出荷先（施工会社）、出荷日、数量、TraceNo、客先注文番号、登録担当者 |

出荷履歴は、出荷日の新しい順に表示されます。

### 8.4 該当がないとき

「製品が見つかりません」と表示された場合は、次を確認してください。

- 入力した番号に誤りがないか
- そのロットが入荷登録されているか

## 9. 有効期限の確認

**画面：有効期限監視・アラート**

出荷済み製品のうち、有効期限が **30日以内** のものを施工会社別に確認できます。

| 項目           | 内容                                                                                  |
| -------------- | ------------------------------------------------------------------------------------- |
| 対象           | 出荷済み（トレーサビリティQR発行済み）で、期限が30日以内のもの                        |
| 除外されるもの | 全量が使用済みのもの                                                                  |
| 表示           | 施工会社ごとにグループ化され、TraceNo・ロット番号・数量・有効期限・残り日数が並びます |

> 施工会社への注意喚起メールの送信は、**管理担当者の業務** です。手順は「操作マニュアル（管理者向け）」をご覧ください。メールは自動送信されません。

<!--pagebreak-->

## 10. 施工会社が製品QRを読み取ったとき

出荷時に貼付したトレーサビリティQRは、施工会社や現場の作業者がスマートフォンの標準カメラで読み取ることができます。

| 項目           | 内容                                                   |
| -------------- | ------------------------------------------------------ |
| 読み取り方法   | スマートフォンの標準カメラでQRを読み取る（アプリ不要） |
| ログイン       | **不要**                                               |
| 表示される内容 | ロット番号、施工先No、トレースNo、有効期限、販売元     |

在庫情報・出荷先の会社名・担当者名など、業務上の情報は表示されません。

## 12. トラブルシューティング

| 症状                         | 考えられる原因             | 対処                                                               |
| ---------------------------- | -------------------------- | ------------------------------------------------------------------ |
| カメラが起動しない           | ブラウザのカメラ許可がオフ | ブラウザの設定でカメラを許可してください                           |
| カメラが起動しない           | HTTP接続になっている       | `https://app.hr-dx.jp` からアクセスしてください                    |
| QRが読み取れない             | ラベルの汚れ・照明不足     | ラベルを拭き、明るい場所で再スキャンしてください                   |
| QRが読み取れない             | ラベルの破損               | 「入荷処理へ進む」から手動で登録するか、ラベルを再発行してください |
| 出荷先が選べない             | 施工会社が未登録           | 管理担当者に納入先登録を依頼してください                           |
| 在庫に表示されない           | 入荷登録がされていない     | 入荷登録を実施してください                                         |
| 在庫に表示されない           | 残数が0になっている        | 出荷済みのため正常です（在庫一覧には残数のあるロットのみ表示）     |
| 出荷登録できない             | 残数不足                   | 別のロットを選び直してください                                     |
| 画面が読み込めない           | 通信エラー・権限不足       | 再ログインするか、「再試行」ボタンを押してください                 |
| メニューに機能が表示されない | 権限が付与されていない     | 管理担当者へ権限の確認を依頼してください                           |
