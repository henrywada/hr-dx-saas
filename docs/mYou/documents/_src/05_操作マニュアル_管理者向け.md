## 1. はじめに

### 1.1 本書について

本書は、ミュー株式会社において製品トレーサビリティ・有効期限管理システム（以下「本システム」）の **管理・運用** を担当される方のための手引きです。

日常の入荷・出荷・照会操作については、別冊「操作マニュアル（ユーザー向け）（MYOU-UM-001）」をご覧ください。

### 1.2 管理担当者の業務

| No  | 業務                           | 頻度           | 参照  |
| --- | ------------------------------ | -------------- | ----- |
| 1   | 納入先（施工会社）マスタの保守 | 随時           | 第3章 |
| 2   | 有効期限の監視とアラート送信   | 週次（推奨）   | 第4章 |
| 3   | 処理ステータスの管理           | アラート対応時 | 第5章 |
| 4   | 使用数の記録                   | 報告都度       | 第6章 |
| 5   | 利用者アカウント・権限の管理   | 随時           | 第7章 |
| 6   | 日常の運用点検                 | 日次・月次     | 第8章 |
| 7   | 障害時の対応                   | 発生時         | 第9章 |

## 3. 納入先（施工会社）マスタの保守

**画面：納入先登録**

出荷先の選択肢、および有効期限アラートの送信先となるマスタです。

### 3.1 新規登録

| 手順 | 操作                                                          |
| ---- | ------------------------------------------------------------- |
| 1    | メニューから **「納入先登録」** を開きます                    |
| 2    | **「新規登録」** ボタンを押します                             |
| 3    | **会社名**（必須）を入力します（100文字以内、正式名称を推奨） |
| 4    | **メールアドレス**（任意）を入力します（255文字以内）         |
| 5    | **「登録する」** を押します                                   |
| 6    | `新規登録が完了しました。` と表示されたら完了です             |

登録すると、**出荷先No（得意先No）** が自動的に採番されます。この番号は出荷リストやトレーサビリティQRラベルに表示されます。

### 3.2 編集・削除

| 操作 | 方法                                                           |
| ---- | -------------------------------------------------------------- |
| 編集 | 一覧の **鉛筆アイコン** を押して内容を修正します               |
| 削除 | 一覧の **ゴミ箱アイコン** を押します（確認ダイアログが出ます） |

### 3.3 メールアドレスに関する注意

| 状態           | 有効期限アラートの動作                                   |
| -------------- | -------------------------------------------------------- |
| 登録済み       | 「アラート送信」ボタンが有効になります                   |
| 未登録（空欄） | 「アラート送信」ボタンが **無効** になり、送信できません |

アラート機能を利用する施工会社には、必ずメールアドレスを登録してください。

### 3.4 削除できないケース

次の場合、施工会社は削除できません。

- その会社への **出荷履歴** がある場合
- その会社宛の **トレーサビリティQR発行履歴** がある場合

このとき、次のメッセージが表示されます。

```
この会社は出荷履歴またはトレーサビリティQR発行履歴から参照されているため
削除できません。
```

取引を終了した会社については、削除ではなく **そのまま残す** 運用としてください（過去の履歴を追跡できるようにするためです）。

### 3.5 メッセージ一覧

| メッセージ                                 | 種別   | 対処                           |
| ------------------------------------------ | ------ | ------------------------------ |
| `新規登録が完了しました。`                 | 成功   | —                              |
| `更新が完了しました。`                     | 成功   | —                              |
| `削除が完了しました。`                     | 成功   | —                              |
| `会社名を入力してください。`               | エラー | 会社名は必須です               |
| `メールアドレスの形式が正しくありません。` | エラー | 書式を確認してください         |
| `この会社は…削除できません。`              | エラー | 履歴があるため削除不可         |
| `出荷先Noの採番に失敗しました。`           | エラー | 時間をおいて再試行してください |

## 4. 有効期限の監視とアラート送信

**画面：有効期限監視・アラート**

出荷済み製品の有効期限を監視し、施工会社へ注意喚起メールを送信します。

> **重要**：本システムはメールを **自動送信しません**。管理担当者が定期的にこの画面を確認し、必要に応じて手動で送信してください。**週1回程度の確認** を推奨します。

### 4.1 監視対象

| 条件     | 内容                                                     |
| -------- | -------------------------------------------------------- |
| 対象     | トレーサビリティQR発行済み（＝施工会社へ出荷済み）のもの |
| 期限条件 | 有効期限が **本日から30日以内**（日本時間基準）          |
| 除外条件 | 未使用数量（出荷数量 − 使用数）が **0** のもの           |
| 送信対象 | 処理ステータスが **「未使用」** のもののみ               |

### 4.2 画面の見方

| 区分       | 内容                                                                                                                          |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------- |
| ヘッダー   | アラート対象の総件数、直近の送信日時                                                                                          |
| 明細       | 施工会社ごとにグループ化され、TraceNo・ロット番号・出荷数量・使用数・未使用数量・有効期限・残り日数・処理ステータスが並びます |
| 送信ボタン | 施工会社ごとに配置。メールアドレス未登録の場合は無効                                                                          |
| 送信履歴   | 直近50件の送信結果（日時・送信先・対象TraceNo・成否）                                                                         |

### 4.3 アラート送信の手順

| 手順 | 操作                                                           |
| ---- | -------------------------------------------------------------- |
| 1    | メニューから **「有効期限監視・アラート」** を開きます         |
| 2    | 画面上部の **アラート対象件数** を確認します                   |
| 3    | 施工会社ごとの明細を確認します                                 |
| 4    | 使用済みのものが含まれていないか確認します（第5章・第6章参照） |
| 5    | 送信対象の施工会社の **「アラート送信」** ボタンを押します     |
| 6    | `アラートメールを送信しました。` と表示されたら完了です        |
| 7    | 画面下部の **アラート送信履歴** で結果を確認します             |

### 4.4 送信されるメールの内容

| 項目 | 内容                                                  |
| ---- | ----------------------------------------------------- |
| 件名 | `【重要】製品有効期限に関するお知らせ（{会社名}様）`  |
| 宛先 | 施工会社マスタに登録されたメールアドレス              |
| 本文 | 対象製品の一覧（ロット番号／数量／有効期限／TraceNo） |

本文に記載される数量は、出荷数量ではなく **未使用数量**（出荷数量 − 使用数）です。

### 4.5 メッセージ一覧

| メッセージ                                     | 種別   | 対処                                         |
| ---------------------------------------------- | ------ | -------------------------------------------- |
| `アラートメールを送信しました。`               | 成功   | 送信履歴で確認してください                   |
| `送信先のメールアドレスが登録されていません。` | エラー | 納入先登録でメールアドレスを設定してください |
| `対象の期限間近製品が見つかりませんでした。`   | エラー | 画面を再読み込みしてください                 |
| `送信対象の未使用製品がありません。`           | エラー | すべて使用済み／アラート無視になっています   |
| `送信に失敗しました。`                         | エラー | 時間をおいて再試行してください               |

### 4.6 送信履歴の確認

送信履歴には、成功・失敗の両方が記録されます。失敗している場合はエラー内容が表示されますので、次を確認してください。

- 施工会社のメールアドレスが正しいか
- メール送信設定（SMTP）が有効か（第10章参照）

## 5. 処理ステータスの管理

有効期限監視画面の各明細には **処理ステータス** があり、アラート送信の対象を制御します。

### 5.1 処理ステータスの種類

| ステータス   | 意味                                     | アラート送信 |
| ------------ | ---------------------------------------- | ------------ |
| 未使用       | 施工会社でまだ使用されていない（初期値） | **対象**     |
| 使用済       | 使用済み                                 | 対象外       |
| アラート無視 | 通知不要と判断したもの                   | 対象外       |

### 5.2 変更手順

| 手順 | 操作                                                       |
| ---- | ---------------------------------------------------------- |
| 1    | 有効期限監視画面で、対象明細の **鉛筆アイコン** を押します |
| 2    | 「未使用」または「アラート無視」を選択します               |
| 3    | 保存します                                                 |

### 5.3 「使用済」を直接選べない理由

「使用済」は、**出荷リストの使用数** から判定される状態です。使用実績を反映する場合は、処理ステータスではなく **出荷リストの使用数を更新** してください（第6章）。使用数が出荷数量に達すると、その明細は自動的に監視対象から外れます。

### 5.4 「アラート無視」の使いどころ

次のような場合に使用します。

- 施工会社から「使用予定がないため返却する」と連絡を受けた
- 既に別の手段で連絡済みで、重複した通知を避けたい
- 廃棄処理が確定している

## 6. 使用数の記録

**画面：出荷リスト**

施工会社から使用実績の報告を受けた際に記録します。使用数は有効期限アラートの対象判定に直結する重要な情報です。

### 6.1 更新手順

| 手順 | 操作                                       |
| ---- | ------------------------------------------ |
| 1    | メニューから **「出荷リスト」** を開きます |
| 2    | 必要に応じて **出荷先** で絞り込みます     |
| 3    | 該当行の **「編集」** ボタンを押します     |
| 4    | 使用数を入力します                         |
| 5    | 保存します                                 |

### 6.2 入力できる範囲

| 条件               | 結果                                        |
| ------------------ | ------------------------------------------- |
| 0 〜 出荷数量      | 正常に登録されます                          |
| 出荷数量を超える値 | `使用数は出荷数量（N）以下にしてください。` |
| マイナス値・小数   | `使用数は0以上の整数で指定してください。`   |

### 6.3 使用数の更新による影響

| 状態              | 有効期限監視画面での扱い                         |
| ----------------- | ------------------------------------------------ |
| 使用数 < 出荷数量 | 未使用分が監視対象として表示されます             |
| 使用数 = 出荷数量 | 監視対象から **除外** されます（期限状況は `-`） |

## 7. 利用者アカウントと権限の管理

### 7.1 権限の考え方

本システムは HR-DX SaaS の権限管理に従い、次の2つの条件を **両方** 満たす場合に、その機能がメニューに表示されます。

| 条件               | 内容                                         |
| ------------------ | -------------------------------------------- |
| テナントの契約機能 | 貴社で利用可能な機能として設定されていること |
| 役割ごとの割当     | その利用者の役割に対して許可されていること   |

いずれかを満たさない場合、その機能はメニューに表示されず、アクセスもできません。

### 7.2 想定する役割分担

| 役割           | 利用する機能                                         |
| -------------- | ---------------------------------------------------- |
| 入荷担当者     | 入荷登録、在庫一覧                                   |
| 出荷担当者     | 在庫一覧、出荷登録、出荷リスト、トレーサビリティ検索 |
| 管理担当者     | 上記すべて、納入先登録、有効期限監視・アラート       |
| システム管理者 | 上記すべて、アカウント管理、権限・メニュー設定       |

### 7.3 アカウント運用のお願い

| No  | お願い                                                                     |
| --- | -------------------------------------------------------------------------- |
| 1   | アカウントは **利用者ごと** に発行し、共用しないでください                 |
| 2   | 退職・異動が発生した場合は、速やかにアカウントを無効化してください         |
| 3   | 権限は業務上必要な最小限としてください                                     |
| 4   | 共用端末では、業務終了後に必ずログアウトしてください                       |
| 5   | パスワードは推測されにくいものを設定し、他システムと使い回さないでください |

### 7.4 メニュー表示に関する問い合わせ

「メニューに機能が表示されない」という相談を受けた場合は、次を確認してください。

| 確認項目                       | 対処                         |
| ------------------------------ | ---------------------------- |
| その利用者の役割が正しいか     | 役割の割当を修正する         |
| 役割に機能が許可されているか   | 役割ごとの機能割当を修正する |
| 貴社の契約機能に含まれているか | サポート窓口へ問い合わせる   |

## 8. 運用点検

### 8.1 日次点検

| No  | 点検項目                                     | 確認方法                 |
| --- | -------------------------------------------- | ------------------------ |
| 1   | 当日の入荷が登録されているか                 | 在庫一覧の入荷日を確認   |
| 2   | 当日の出荷が登録されているか                 | 出荷リストの出荷日を確認 |
| 3   | 出荷分のトレーサビリティQRが貼付されているか | 現場での確認             |

### 8.2 週次点検

| No  | 点検項目                                       | 確認方法           |
| --- | ---------------------------------------------- | ------------------ |
| 1   | 有効期限が30日以内の出荷済み製品がないか       | 有効期限監視画面   |
| 2   | 該当がある場合、施工会社へアラートを送信したか | アラート送信履歴   |
| 3   | 期限切れ（赤表示）の在庫がないか               | 在庫一覧の期限状況 |

### 8.3 月次点検

| No  | 点検項目                                     | 確認方法         |
| --- | -------------------------------------------- | ---------------- |
| 1   | 在庫の実数とシステム上の残数が一致しているか | 棚卸との突合     |
| 2   | 施工会社のメールアドレスが最新か             | 納入先登録の一覧 |
| 3   | 退職者・異動者のアカウントが残っていないか   | 利用者一覧       |
| 4   | 使用数の記録が実態と合っているか             | 出荷リスト       |

### 8.4 在庫差異が見つかった場合

| ケース                 | 対応                                                       |
| ---------------------- | ---------------------------------------------------------- |
| 実在庫 > システム残数  | 入荷登録の漏れ。該当ロットを入荷登録して数量を加算する     |
| 実在庫 < システム残数  | 出荷登録の漏れ。該当ロットの出荷を登録する                 |
| 返品により在庫が戻った | 該当ロットを入荷登録する（再入荷の警告が出ますが正常です） |

## 9. 障害時の対応

### 9.1 一次切り分け

| 症状                       | 確認事項                             | 対処                                  |
| -------------------------- | ------------------------------------ | ------------------------------------- |
| 画面が開かない             | 他の端末でも同様か                   | 全端末で発生する場合はサポートへ連絡  |
| ログインできない           | メールアドレス・パスワードは正しいか | パスワード再設定を案内                |
| カメラが起動しない         | ブラウザのカメラ許可、HTTPS接続か    | 許可設定を確認、`https://` でアクセス |
| メールが届かない           | 送信履歴に成功と記録されているか     | 成功なら受信側の迷惑メール設定を確認  |
| メール送信が失敗する       | 送信履歴のエラー内容                 | メール設定（SMTP）をサポートへ確認    |
| 特定の機能だけ表示されない | 利用者の役割・権限                   | 第7.4節を参照                         |

### 9.2 エスカレーション時にお伝えいただきたい情報

| No  | 情報                                                         |
| --- | ------------------------------------------------------------ |
| 1   | 発生日時（できるだけ正確に）                                 |
| 2   | 操作していた画面名                                           |
| 3   | 画面に表示されたメッセージ（画面キャプチャがあると確実です） |
| 4   | 対象のロット番号・TraceNo・施工会社名                        |
| 5   | 使用していた端末とブラウザ                                   |
| 6   | 他の利用者・端末でも再現するか                               |

### 9.3 データ復旧について

データベースは基盤側で自動的にバックアップされています。誤操作によるデータ消失が疑われる場合は、**追加の操作を行わずに** サポート窓口へご連絡ください。

## 10. システム設定に関する情報

以下は、サポート窓口や保守担当と連絡を取る際の参考情報です。設定変更にはシステム側での作業が必要です。

### 10.1 主な設定値

| 項目                             | 設定値   | 変更可否                   |
| -------------------------------- | -------- | -------------------------- |
| 有効期限アラートの対象日数       | 30日     | 変更にはシステム改修が必要 |
| 在庫一覧の取得件数上限           | 1,000件  | 同上                       |
| 出荷リストの取得件数上限         | 500件    | 同上                       |
| アラート送信履歴の表示件数       | 50件     | 同上                       |
| 入荷数量の上限                   | 100,000  | 同上                       |
| トレーサビリティQRの印刷部数上限 | 1,000部  | 同上                       |
| 日付の基準タイムゾーン           | 日本時間 | 変更不可                   |

### 10.2 メール送信設定

アラートメールの送信には、メールサーバー（SMTP）の設定が必要です。次の項目がシステム側に設定されています。

| 項目           | 内容                                   |
| -------------- | -------------------------------------- |
| 送信サーバー   | SMTPホスト・ポート                     |
| 認証情報       | ユーザー名・パスワード                 |
| 送信元アドレス | メールの差出人として表示されるアドレス |

メールが送信できない場合は、これらの設定をサポート窓口へご確認ください。

### 10.3 番号体系

| 番号       | 書式                | 採番方法                                       |
| ---------- | ------------------- | ---------------------------------------------- |
| ロット番号 | `LOT-YYYYMMDD-NNNN` | 入荷登録時。QR未スキャン時は当日通番で自動採番 |
| TraceNo    | `YYYYMMDD-NNNN`     | 出荷登録1件につき1つ自動採番                   |
| 出荷先No   | 連番                | 施工会社の新規登録時に自動採番                 |

## 11. 現行バージョンの機能範囲

導入検討時にご提示した内容のうち、現行バージョンでの取り扱いは次のとおりです。

| 項目                            | 現行バージョン | 備考                                                 |
| ------------------------------- | -------------- | ---------------------------------------------------- |
| 有効期限アラートの手動送信      | **提供**       | 管理担当者が画面から送信                             |
| 有効期限アラートの **自動送信** | 未提供         | 担当者による定期確認・手動送信での運用をお願いします |
