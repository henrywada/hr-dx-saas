# プラン別 有効サービス一覧

**対象読者：** LP・サインアップ画面の制作担当、営業・企画担当
**最終更新：** 2026-08-17
**出典：** Supabase の `plan_config` / `tenants`（テンプレート）/ `tenant_service` / `service`

> LP のプラン選択画面に表示する「各プランで使える機能」の一覧です。
>
> プランごとの有効サービスは、`plan_config.template_tenant_name` が指すテンプレートテナント（`PlanFree` / `Plan100` …）の `tenant_service` で定義されます。新規テナントの登録時、このテンプレートから `tenant_service` がコピーされる仕組みです。
>
> **現在サービス設定が完了しているのは無料プランのみです。** 有料 4 プランは `tenant_service` が未登録のため、本書では無料プランのみ機能を掲載しています。

> **LP 表示上の注意：** `available = false` のプランは、LP・サインアップの双方で「準備中」として扱われます。現在 `true` は無料プランのみです。有料プランを公開する際は、`plan_config.available` を `true` に切り替え、対応する Stripe の環境変数を設定してください。
>
> **無料プランは無期限です**（`contract_months = NULL` のため `contract_end_at` を設定せずに登録します）。2026-08-17 に「登録日から 3 ヶ月」から変更しました。有料プランは登録日から 12 ヶ月で契約終了日を迎えます。

## 無料プランの有効サービス

全 14 機能。**ストレスチェックを中心とした構成**で、法定のストレスチェック実施から労基署報告までが一通り揃っています。組織の健康度可視化を入口に据えた設計です。

### 管理者向け（9 機能）

#### ストレスチェック（7 機能）

| サービス名 | 概要 |
| --- | --- |
| 実施（期間・対象部署・対象者）の管理 | ストレスチェックの実施期間・対象部署・質問数を設定します。事業場単位の集計は拠点マスタで登録した拠点を使います。 |
| 拠点（事業場）マスタ | 集団分析・進捗の拠点別表示や労基署報告の単位となる事業場を登録します。アンカー部署を紐づけて従業員を事業場に割り当てます。 |
| ストレスチェック進捗管理 | 全体進捗と拠点ごとの受検状況をリアルタイムで確認。受検率や未受検者の把握、リマインド送信ができます。 |
| 組織健康度ヒートマップ分析 | 結果に基づき組織全体の健康度をヒートマップで可視化。全社・事業所・部署・階層別に組織の状態を多角的に把握できます。 |
| 高ストレス者一覧（人事用） | 面談勧奨からオンラインでの申出受付、産業医による就業上の措置の記録までを一気通貫で管理。機密性の高い医療情報は人事データと分離して保護します。 |
| パルス×ストレス分析 | 年 1 回の健康リスク調査・毎月のエンゲージメント・日次コンディション記録を統合し、従業員の総合的な状態を分析します。 |
| 労基署報告用データ集計 | 心理的な負担の程度を把握するための検査結果等報告書に必要なデータを、実施期間ごとに集計し CSV で出力します。 |

#### 従業員・組織登録（2 機能）

| サービス名 | 概要 |
| --- | --- |
| 従業員の登録 | 登録済み従業員の一覧表示、新規追加、情報の編集、部門・役割の割り当てができます。現在の登録状況と契約容量も確認できます。 |
| 組織の登録 | 貴社の組織構成や部門、階層を登録し、組織管理の基盤を構築します。 |

### 従業員向け（5 機能）

#### ストレスチェック（2 機能）

| サービス名 | 概要 |
| --- | --- |
| ストレスチェック受検 | 実施中のストレスチェックに回答できます。対象期間中かつ対象者の場合のみ質問フォームが表示されます。 |
| ストレスチェック結果の確認 | 自身の結果をグラフと要約で確認できます。事業者への結果提供の同意設定もここで行えます。 |

#### パルス＆サーベイ（3 機能）

| サービス名 | 概要 |
| --- | --- |
| 私のコンディション記録・推移確認 | その日のコンディションを記録し、過去 30 日間のスコア推移をグラフで確認できます。 |

## 有料プランの状況と残作業

Plan100 / Plan300 / Plan500 / Plan1000 は、**テンプレートテナントは 5 件とも作成済みですが、`tenant_service` が 0 件**です。この状態で有料プランを公開すると、契約したテナントに利用可能な機能が 1 つも割り当てられません。

### 公開までに必要な作業

1. **各テンプレートテナントへのサービス割当**
   `/saas_adm/system-master` の「Plan テナントテンプレート」タブから、プランごとに有効サービスを設定します。無料プラン（14 機能）を基準に、上位プランで何を追加するかを決める必要があります。参照できる全機能の一覧は [機能カタログ](./機能カタログ.md)（従業員 31 + 管理者 75 = 106 機能）です。

2. **`plan_config.available` の切り替え**
   サービス設定の完了後、公開するプランの `available` を `true` にします。これが `false` の間は LP・サインアップの双方で「準備中」と表示されます。

3. **Stripe 価格 ID の環境変数設定**
   `STRIPE_PLAN100_PRICE_ID` など、各プランに対応する環境変数を Vercel に登録します。
