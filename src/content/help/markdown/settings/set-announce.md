## 目的

この画面は、人事から全社員または特定の従業員へお知らせを掲載するための画面です。登録した内容は、従業員トップ画面（/top）の「お知らせ」カードと、その一覧ページに自動的に反映されます。

## お知らせ管理での登録の仕組み

1. 「お知らせを追加」から、タイトル・本文・公開日時・掲載期限・対象・個人宛・NEW バッジ表示・表示順を入力して登録します。
2. 登録すると、公開日時を過ぎ、かつ掲載期限（設定していれば）を過ぎていない間、対象の従業員のトップ画面に自動的に表示されます。公開ボタンのような別操作は不要です。
3. 公開日時を未来の日時にすると予約投稿になり、その日時が来るまで表示されません。
4. 掲載期限を過ぎると自動的に非表示になります（レコード自体は削除されないため、編集で期限を延ばして再掲載することもできます）。
5. 「個人宛」を指定しなければ全社員が対象です。指定すると、その従業員のみに表示される個人宛のお知らせになります。

## 入力項目の説明

- **タイトル**：必須。お知らせカードの見出しになります。
- **本文**：任意。カード内の説明文になります。
- **公開日時**：このお知らせが表示され始める日時です。未来日時にすると予約投稿として扱われます。
- **掲載期限（任意）**：設定した日時を過ぎると自動的に非表示になります。無期限にする場合は空欄のままにします。
- **対象**：一覧・トップ画面に表示する説明用のラベルです（例：「全社員対象」「新入社員向け」）。誰に配信するかを絞り込む機能ではありません。配信範囲を絞り込めるのは「個人宛」の指定のみです。
- **個人宛（任意）**：特定の従業員のみに表示したい場合に選択します。未選択の場合は全社員対象です。
- **NEW バッジを表示する**：オンにすると、トップ画面の当該お知らせに NEW バッジが付きます（新規追加時は既定でオン）。日数経過で自動的に外れる仕組みではなく、手動でオフに切り替えるまで表示され続けます。
- **表示順**：数値が小さいほど先に表示されます。同じ値の場合は公開日時が新しい順に並びます。

## TOP画面「お知らせ」フィードの仕組み

従業員トップ画面の「お知らせ」カードは、この画面で登録した内容だけでなく、アプリの各機能が生成する通知もあわせて1つのフィードとして表示しています。

- **お知らせ（本画面で登録）**：人事が掲載した内容がそのまま表示されます。
- **悩み・相談窓口**：担当スタッフ（人事・産業医・保健師・安全衛生委員等）宛てに、対応が必要な未対応の相談が届いている場合に件数で通知します。
- **感謝・称賛（Kudos）**：自分宛に新着のメッセージが届いている場合に件数で通知します。
- **アンケート**：自分に割り当てられた未回答のアンケートがある場合、回答期限とともに通知します。
- **入社・退社フロー**：自分に割り当てられた未完了タスクがある場合、期限とともに通知します（期限超過は警告表示になります）。
- **eラーニング**：自分に割り当てられた未受講の講座がある場合、受講期限とともに通知します。
- **1on1**：近日（3日以内は要注意扱い）予定されている1on1面談を通知します。
- **キャリア面談**：近日予定されているキャリア面談を通知します。
- **健康診断**：直近の健康診断結果から、産業医または保健師との面談が推奨されている場合に通知します。
- **残業・36協定コンプライアンス**：月45時間・100時間・複数月平均80時間などの残業基準を超えたアラートが出ている場合に通知します。

## いつ・どんな仕組みで通知されるか

- リアルタイムのプッシュ通知ではありません。対象の従業員がトップ画面や通知一覧画面を開くたびに、その時点の最新データをもとにサーバー側で通知内容を組み立てて表示します。
- 表示順は「未読を優先 → 重要度（緊急・警告・要対応・お知らせの順） → 期限が近い順 → 発生日時が新しい順」で決まります。
- 通知には既読・未読の状態があります。多くの通知は個別に既読にできますが、相談件数・Kudos件数のように「件数の集計」で成り立っている通知は、一度既読にすると新着が来ても二度と未読に戻せなくなるため、既読トグルの対象外です。
- 直近分はトップ画面のカードに表示され、すべての通知は「お知らせ」メニューの一覧ページでまとめて確認・一括既読ができます。

## 注意事項

- お知らせの削除は取り消せません。掲載を終了したいだけの場合は、削除ではなく掲載期限の設定を検討してください。
- 「対象」欄は表示ラベルにすぎず、実際の配信制御は「個人宛」の指定でのみ行われます。
- eラーニング・1on1・キャリア面談・健康診断・残業コンプライアンスの通知は、各機能側のデータから自動生成されるため、この画面から編集・削除はできません。内容を変更したい場合は、それぞれの機能画面で操作してください。
